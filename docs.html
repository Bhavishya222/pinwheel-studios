Pinwheel Compose & Pinwheel Thread — Complete Beginner's Tutorial

Covers Pinwheel Compose (Package 1), Pinwheel Motion (included in Compose), and Pinwheel Thread (Package 2). Assumes zero prior Unity UI experience.

Applies to: Pinwheel Compose, Motion & Thread Chapter 1

What Pinwheel Compose, Motion & Thread Do

Think of building game menus like building a room: one tool builds the walls, one brings them to life, and one wires the light switches. The Pinwheel Studios UI Suite packages three pillars into two independent Unity packages:

Asset / ModuleRoleWhat It DoesUnity Menu Location
Pinwheel Compose
Package 1		 Screen Builder & Themer Builds Main Menus, Settings, Language popups, and Lobby screens in one click. Edit text, icons, colors, and fonts live, and export .pwui files for teammates. Tools → Pinwheel Studios → Pinwheel Compose
Pinwheel Motion
Included in Compose		 UI Animation Components Two Inspector components (Button Feel & Panel Intro) adding hover/click feedback and OnEnable title/card reveals with zero Animator controllers and zero code. Add Component → Pinwheel Studios → Pinwheel Motion
Pinwheel Thread
Package 2		 Visual Flow Router A rename-proof visual node grid where you drag Buttons and Menus from your Hierarchy, draw wires, check the live Health Badge, and auto-generate one clean C# router script. Tools → Pinwheel Studios → Pinwheel Thread
Standalone Assembly Definitions (.asmdef) Pinwheel Compose and Pinwheel Thread ship with separate .asmdef files. You can install Compose alone, Thread alone, or both together with zero compile errors. All Pinwheel Motion animations are zero-GC procedural C#, and Thread compiles to one C# router script without Inspector OnClick lists.

4-Step First-Time Setup

  1. Import Package(s): Double-click Pinwheel_Compose_v1.1.unitypackage and/or Pinwheel_Thread_v1.1.unitypackage (or use Assets → Import Package → Custom Package).
  2. Import TextMeshPro Essentials: In a new project, run Window → TextMeshPro → Import TMP Essential Resources. Without this, text labels may appear blank.
  3. Verify Top Menu Bar: Wait 2 seconds for .asmdef compilation and confirm Tools → Pinwheel Studios lists Pinwheel Compose and Pinwheel Thread.
  4. Set Game View to 16:9: Select 16:9 (or 1920×1080) in Game View. Compose creates a Canvas and EventSystem automatically when you spawn your first screen.

Building Main Menu, Settings, Language & Lobby Screens

  1. Open Tools → Pinwheel Studios → Pinwheel Compose and dock it next to Game View.
  2. Under CREATE STANDALONE SCREEN, click Main Menu to generate a 1920×1080 Canvas with PLAY, HOST LOBBY, JOIN LOBBY, SETTINGS, QUIT, and a watermark.
  3. Click Settings for a 4-category Settings screen (VIDEO, AUDIO, CONTROLS, ACCESSIBILITY) with a single ScrollView and BACK | APPLY | RESET footer.
  4. Use Solo (green button in SCENE SCREENS) to isolate one screen in Game View so menus never overlap while editing.
  5. Click Icon Submenu to spawn a centered Language popup (English, Español, Français, 日本語) with flag icon slots and an active gold indicator dot.

Live Editing (With Full Ctrl+Z Undo)

  • Main Menu: Switch between Left-Anchored and Centered Card, assign a Game Logo Sprite, restyle buttons (Primary / Secondary / Danger), or reorder with ▲/▼.
  • Settings Menu: Edit Top Category Tabs, add < Stepper >, Slider, Toggle, Keybind, or Submenu ▸ rows, and toggle 24×24 Left Icons.
  • Icon Submenus: Toggle live between 1-Column Icon List and 2-Column Icon Grid.
  • Create Lobby & Lobby Room: Multiplayer screens with Room Code bars, TMP_InputFields, Max Players steppers, Player Roster rows, and a toggleable Side Loadout Panel.
Applies to: Pinwheel Compose (Package 1) Chapter 4

Themes, Fonts & Bringing Your Own Custom UI

Click Edit Theme in Compose's top bar to open your saved PWUI_Theme ScriptableObject. Choose a preset (Dark Fantasy, Blood & Iron, Modern Slate, or Horror Minimal), assign your TextMeshPro Primary/Header fonts and 9-slice sprites, and click APPLY THEME TO ALL SCENE SCREENS.

3 Ways to Mix Custom Art & Panels

  • 1. Drop Into a Custom Slot: Create Lobby, Lobby Room, and Custom Panel include Custom Slots (+ Add Slot). Drop in any UI prefab and click Insert Prefab.
  • 2. Register Any Hand-Built Panel: Select your custom panel in the Hierarchy and click + Register Selected UI Panel. It receives Solo Preview with Lock Theme Sync = ON by default.
  • 3. Theme Prefab Overrides: In PWUI_Theme Section 5, assign custom Button or Player Row prefabs so newly generated menus spawn your own prefabs automatically.
Applies to: Pinwheel Motion (Included in Compose) Chapter 5

Wiring Buttons to Menus on the Node Grid

Pinwheel Thread flows strictly Left-to-Right: Purple: Start Setup → Blue: Triggers → Gold: Actions → Green: Targets.

  1. Open Tools → Pinwheel Studios → Pinwheel Thread.
  2. Drag MainMenu_Screen from Hierarchy onto the grid as a Screen Buttons Card (Blue).
  3. Drag MainMenu_Screen and SettingsMenu_Screen onto the grid as Menu Targets (Green).
  4. Add Lifecycle → Start Disabled (Purple) and wire Disable On Start → Start Off on SettingsMenu_Screen.
  5. Add Actions → Switch Menu (Gold): wire MainMenu_Screen [SETTINGS] → In, Open → SettingsMenu_Screen, and Close → MainMenu_Screen.
  6. Wire both Btn_Back and a scoped Escape / Back Key (Blue) into the same Back (Auto-History) (Gold) node (Multi-Input creates In 2 automatically).
  7. Add Refresh Panel (Gold) wired to SettingsMenu_Screen so sub-panels close, scrollbars reset to top, and intros replay on every visit.
  8. Click Auto-Tidy, confirm the Health Badge shows ✓ Ready, and click COMPILE & CONNECT.
Wiring Settings Top Tabs (VIDEO | AUDIO | CONTROLS | ACCESSIBILITY) Drag SettingsMenu_Screen onto the grid as a Screen Buttons Card, create 4 Scroll To Section (Gold) nodes pointing to Settings_ScrollView and each section RectTransform, wire each tab port, and click COMPILE & CONNECT.

v1.1 Reliability Protections

  • Rename-Proof & Move-Proof (GlobalObjectId): Tracks both GlobalObjectId and Hierarchy Path to self-heal moved or renamed objects automatically.
  • Duplicate Sibling Protection: Distinctly tracks same-named siblings (Button[#1] vs Button[#2]).
  • Live Pre-Compile Health Badge: Click ⚠ N Issues ▾ to jump to broken nodes or run 1-click Auto-Repair Paths.
  • Prefab Mode Guard & Multi-Scene Support: Warns if compiling inside isolated Prefab Mode and resolves additively loaded scenes.

Sending UI Across Different Unity Projects

  • Export Menus (.pwui — Pinwheel Compose): Click Export .pwui (5–15 KB file), Copy (clipboard text), or Export Bundle. Your teammate imports or pastes inside their active scene and gets live-editable UI immediately.
  • GUID-Free Safety: .pwui files store Font and Sprite names instead of raw project GUIDs. Keep Import Uses Active Theme = ON to adopt the receiving project's fonts, sprites, and colors.
  • Export Flows (.pwthread — Pinwheel Thread): Click Share ▾ → Export Graph (.pwthread). Local GlobalObjectIds are stripped automatically so your teammate imports the graph and clicks COMPILE & CONNECT.
Applies to: Pinwheel Thread (Package 2) Chapter 9

Connecting Gameplay & PurrNet Code (Custom Hook)

Never hand-edit PinwheelThread_UIFlow.cs because re-compiling overwrites it. Add a Custom Hook (Gold) node, set its C# Event Name (e.g., OnCreateLobbyClicked), compile, and subscribe from your own script:

LobbyNetworkBridge.cs — Pinwheel Thread Custom Hook Example 
using UnityEngine;

public class LobbyNetworkBridge : MonoBehaviour
{
    [SerializeField] private PinwheelThread_UIFlow uiFlow;

    private void OnEnable()
    {
        if (uiFlow != null)
            uiFlow.OnCreateLobbyClicked += HandleCreateLobby;
    }

    private void OnDisable()
    {
        if (uiFlow != null)
            uiFlow.OnCreateLobbyClicked -= HandleCreateLobby;
    }

    private void HandleCreateLobby()
    {
        // Trigger your PurrNet lobby creation or game logic here
        Debug.Log("[Pinwheel Studios] Creating PurrNet Lobby...");
    }
}

Unity MeshLOD Studio — Documentation

Prefab-first LOD management and conversion tool. Repository: github.com/Bhavishya222/Unity-MeshLOD-Studio

Applies to: Unity MeshLOD Studio Quick-Start Guide

Overview, Installation & Usage

Unity's built-in Generate Mesh LODs feature lacks support for Static Batching, GPU Instancing, per-LOD material overrides, and custom transition thresholds. Unity MeshLOD Studio losslessly extracts generated Mesh LOD index buffers into compact standalone meshes and builds configurable LODGroup setups directly on your Prefab assets.

Core Features

  • Prefab-First Workflow: Modifies the source .prefab asset safely so scene instances inherit updates without breaking instance-specific overrides.
  • Lossless LOD Extraction: Uses Mesh.AcquireReadOnlyMeshData to extract and vertex-compact individual LOD levels without modifying original FBX models.
  • Zero-Conflict LODGroups: Preserves your original MeshFilter/MeshRenderer for LOD0 to maintain FileIDs, scripts, and scene material overrides while building child nodes for LOD1+.
  • Batch Optimizer & Scene Auto Setup: Batch-process hundreds of prefabs or scan a full scene to group and update unique source prefabs.
  • Preset Manager: Save, reuse, import, and export JSON presets (High Quality, Balanced, Performance) mapping screen-relative heights or real-world distances.

Installation

  1. Download or clone Unity-MeshLOD-Studio from GitHub.
  2. Place the Assets/Editor/MeshLODStudio folder into your Unity project.
  3. Allow Unity to compile the included .asmdef file.
  4. Open via Tools → MeshLOD Studio → Open Studio.

Usage

  1. Ensure your 3D models have Generate mesh LODs enabled in their Model Importer (or use the 1-click enable button inside the tool).
  2. Open Tools → MeshLOD Studio → Open Studio.
  3. Select a .prefab asset in your Project window and review the structural analysis in the Prefab Studio tab.
  4. Switch to the Mesh LOD Converter tab, select an optimization Preset, and click Convert Selected Objects & Save Prefab.

Unity URP World Rescaler — Documentation

One-click scene, Terrain, collider, and URP light rescaler. Repository: github.com/Bhavishya222/Unity-URP-World-Rescaler

Applies to: Unity URP World Rescaler Quick-Start Guide

Overview, Installation & Usage

Scaling a root GameObject in Unity breaks multi-tile terrain physics and ignores light ranges. Unity URP World Rescaler calculates exact proportions and clones terrain assets so oversized maps shrink cleanly in one click.

Features

  • Safe Hierarchy Scaling: Repositions root objects without skewing nested terrain scale constraints.
  • Terrain Cloning: Duplicates TerrainData and TerrainLayers before modifying them to preserve painted splatmaps and prevent stretched textures.
  • Physics Sync: Automatically updates invisible TerrainCollider dimensions to match the visual mesh.
  • URP Lighting Scaling: Scales Point/Spot light ranges and Camera clip planes to match the new world size, with an optional toggle to adjust light intensity.

Installation

  1. Download WorldRescalerWindow.cs from GitHub.
  2. Drop it anywhere inside an Assets/Editor folder in your Unity project.

Usage

  1. Open Tools → World Rescaler from the top menu bar.
  2. Set your Scale Factor (for example, if your world is 5× too big, set Scale Factor to 0.2).
  3. Check the options relevant to your scene (Terrain scaling, URP light ranges, etc.).
  4. Click Scan Active Scene to check for structural blockers, then click Apply Rescale.
Backup & Re-Bake Note Always save a project backup before modifying scene scales. Baked lightmaps, NavMesh data, and fog distances will need to be re-baked manually after rescaling.
