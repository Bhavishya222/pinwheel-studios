Pinwheel Compose & Pinwheel Thread — Complete Beginner's Tutorial

Covers Pinwheel Compose (Package 1), Pinwheel Motion & Pinwheel Localization (included in Compose), and Pinwheel Thread (Package 2). Assumes zero prior Unity UI experience.

Applies to: Compose, Motion, Localization & Thread Chapter 1

What Pinwheel Compose, Motion, Localization & Thread Do

Think of building game menus like building a room: Compose builds the walls, Motion brings them to life, Localization translates every sign, and Thread wires the switches and memory.

What's New in v1.6 1-click Menu Presets (Pause, Confirm Popup, Game Over, Credits), Nested Sub-Panels inside any screen, a Canva-style Block Composer for custom panels, flattened Pinwheel Motion Inspectors with live Edit-Mode Previews, a 2-tab Pinwheel Localization Manager (AI copy/paste + Anti-□□□ Font Check), and Pinwheel Thread's silent automatic PlayerPrefs memory with zero Save buttons.

4-Step First-Time Setup

  1. Import Package(s): Double-click Pinwheel_Compose_v1.6.unitypackage and/or Pinwheel_Thread_v1.6.unitypackage (or Assets → Import Package → Custom Package) and click Import.
  2. Import TextMeshPro Essentials: In a fresh project, run Window → TextMeshPro → Import TMP Essential Resources. Without this, text labels may appear blank.
  3. Verify Top Menu Bar: Wait 2 seconds for compilation. Under Tools → Pinwheel Studios you will see Pinwheel Compose, Pinwheel Localization, and Pinwheel Thread.
  4. Set Game View to 16:9: Set Game View to 16:9 (or 1920×1080) and dock Pinwheel Compose beside it. Compose creates a Canvas and EventSystem automatically when spawning your first screen.

Building Menus, Nested Sub-Panels & Custom Block Panels

  1. Open Tools → Pinwheel Studios → Pinwheel Compose. The single top toolbar holds Theme, Edit, Apply Theme, Transfer ▾, Show All, and Refresh.
  2. Under ADD MENU PRESET (bottom-left), click Main Menu, Pause Menu, Settings, Language, Create Lobby, or Custom Panel. Click + More Menu Presets ▾ for Lobby Room, Confirm & Quit Popup, Game Over Screen, Focused Settings (Audio / Controls / Video), Icon Submenus, Credits Screen, or a Blank Empty Custom Panel.
  3. Auto-Solo Preview: Enabled by default at the top of the sidebar. Clicking any screen selects it and hides sibling screens so Game View stays clean.
  4. Edit-First Inspectors: Edit labels in any casing (no forced ALL-CAPS), click Dup to clone rows/buttons, reorder with ▲/▼, remove with ✕, and undo freely with Ctrl+Z.

Screen-by-Screen Highlights

  • Main Menu & Pause Menu: Edit, style (Primary / Secondary / Danger), duplicate, or add buttons at the top. Flip between Left-Anchored and Centered Card, assign a Game Logo Sprite, or edit the Studio Watermark.
  • Settings Menu (Game-Ready Defaults): Spawns with realistic rows (Quality, Fullscreen, V-Sync, Brightness, Master Volume, Mouse Sensitivity, etc.) and a clean BACK | RESET footer designed for Thread's automatic PlayerPrefs saving. Added or renamed sections? Open Top Category Tabs and click Sync to Sections in 1 click.
  • Icon Submenus (Language, Difficulty, Maps): Language spawns prefilled with all 6 Pinwheel languages (English, Português, 简体中文, 日本語, Русский, Español). Switch live between 1-Column Icon List and 2-Column Icon Grid, assign flag sprites, and click the single-active ● Active pill.

Nested Sub-Panels Inside Any Screen (New in v1.6)

  1. Select any parent screen (such as Settings) in the left sidebar.
  2. Scroll to Nested Sub-Panels on the right pane and click + Add Sub-Panel ▾ (Keybinds List Sub-Panel, Mini Options List, Icon Picker, Confirm Popup, or Custom Block Panel).
  3. The sub-panel appears indented (↳ Keybinds) under its parent. Clicking it keeps the parent screen visible behind it so you design the true layered overlay while isolating its controls.

Canva-Style Block Composer for Custom Panels (New in v1.6)

  • Stack Modular Blocks: Under ADD BLOCK, click + Heading, + Text, + Image, + Button, + 2-Btn Row, + Option Row ▾ (Keybind, Slider, Toggle, Stepper, Input, Submenu Trigger), + Divider, or + Spacer.
  • Quick Size & Card Style: 1-click card sizes (Compact, Medium, Wide, Tall), live Block Spacing slider, and Show Header / Show Footer toggles.
  • Inline Block Tweaks: Click ⚙ on any block to adjust font size, Left/Center/Right alignment, image height, or button styles—automatically synced to your active PWUI_Theme.

Themes, Fonts & Bringing Your Own Custom UI

Click Edit next to Theme in Compose's top bar to inspect your saved PWUI_Theme ScriptableObject. Pick a preset (Dark Fantasy, Blood & Iron, Modern Slate, or Horror Minimal), assign your TMP Primary Font, optional Header Font, and custom 9-slice sprites, then click Apply Theme to update every unlocked screen, block, and control instantly.

3 Ways to Mix Your Own Custom UI

  • 1. Custom Prefab Slots: Expand Custom Prefab Slots on any screen, click + Slot, drag your Unity UI prefab into Prefab to Insert, and click Insert—with full Undo support.
  • 2. Register Any Hand-Built Panel: Expand Custom Canvas / Register at the bottom-left of Compose, select your hand-built UI panel in the Hierarchy, and click + Register Selected UI Panel. It gains Solo Preview immediately with Lock Theme Sync = ON.
  • 3. Auto-Tag Hand-Built Children: On a Custom Panel, expand Bring-Your-Own UI Tools and click Auto-Tag Untagged Child UI for Theme Sync to opt custom Buttons, Inputs, and Texts into your Theme.

Tactile Hover Juice, Text FX & Edit-Mode Previews

In v1.6, both Pinwheel Motion Inspectors (PWUI_ButtonFeel and PWUI_PanelIntro) use a flat at-a-glance layout with 1-Click Feel Recipes and core dropdowns at the top, while spring curves, audio clips, child cascades, and overrides stay in clean foldouts.

Part A: Button Hover & Click Juice (PWUI_ButtonFeel)

  1. Select one or multiple Buttons → Add Component → Pinwheel Studios → Pinwheel Motion → Button Feel.
  2. Pick a 1-Click Feel Recipe: Click Obsidian, Gothic, Velvet, Arcane, or Minimal to pair matching Spring Motion, per-character Text FX, and Hover Accent automatically.
  3. Customize & Preview in Edit Mode: Adjust Motion Preset, Intensity, Text FX (Gold Shimmer, Wave Ripple, Tracking Expand, Parallax Slide, Type Pop, Horror Tremble, Glitch Slice), or Hover Accent (Left Edge Bar, Bottom Line, Diagonal Sheen). Click ▶ Preview Hover or ▶ Preview Click right in Edit Mode without entering Play Mode.
  4. Optional Tuning & SFX: Expand Spring Tuning for the live 2nd-order spring curve (Snappiness & Bounce) or Audio Feedback for pitched hover/click AudioClips.

Part B: OnEnable Panel, Title & Popup Reveals (PWUI_PanelIntro)

  1. Select any Title, Logo, Card, or Popup → Add Component → Pinwheel Studios → Pinwheel Motion → Panel Intro.
  2. Pick an Enter Preset (Slide Up + Fade, Fade In, Slide From Left/Right, Scale Pop, Heavy Slam, Title Drop), optional Title Text FX (Letter Wave In, Cinematic Tracking, Gold Shimmer Sweep, Gothic Flicker, Letter Drop In, Impact Spread), and optional Idle Loop.
  3. Click ▶ Preview Enter or ▶ Preview Exit in Edit Mode (or ▶ Replay Enter in Play Mode). Previews automatically restore rest positions before saving or switching scenes.
Smart Child Cascade (Auto-Stagger) Select a Buttons container → add Panel Intro → expand Child Cascade (Auto-Stagger) → check Auto-Stagger Children → click Apply Panel Motion to Content Children. v1.6 automatically skips purely decorative dividers, backdrops, and spacers so only real content animates.

Translating Your Game in 3 Steps (Pinwheel Localization)

Open Tools → Pinwheel Studios → Pinwheel Localization. Click Create Default Language Table (6 Starter Languages) to generate PWUI_LanguageTable.asset inside Resources/PinwheelStudios/ pre-loaded with English (en), Portuguese (pt), Simplified Chinese (zh-CN), Japanese (ja), Russian (ru), and Spanish (es).

The 3-Step Translation Loop (Tab 1: Translate & Scene)

  1. Click '1. Auto-Localize Scene': Scans every Compose screen in the active scene, automatically skips dynamic numbers/symbols, user input text, and Language Button labels, attaches PWUI_LocalizedText, and registers deduplicated keys.
  2. Click '2. Copy AI Prompt (Missing)': Copies all untranslated keys as a structured prompt ready to paste into any AI chat for button-friendly JSON translations.
  3. Click '3. Paste AI Reply': Paste the AI's JSON reply—Pinwheel Localization strips markdown fences automatically and merges every translation into your table. Prefer spreadsheets? Use CSV ▾ in the top bar for Excel-safe UTF-8 BOM Export/Import.

Fonts, Anti-□□□ Protection & Safe Live Preview (Tab 2: Languages & Fonts)

  • Assign Non-Latin TMP Fonts: Leave Latin languages empty to keep your Theme font. Assign Dynamic SDF TMP fonts (e.g., Noto Sans SC, JP, Cyrillic) to zh-CN, ja, and ru. If a font is Static or missing Multi-Atlas Textures, click the 1-click Fix Font button in the warning banner.
  • Wire Language Switcher Buttons: Add PWUI_LanguageButton to each button in your Language Submenu and pick its Target Language. Click Sync Language Buttons in Scene in Tab 2 so each button renders in its native script (e.g., 日本語) with its own font.
  • Safe Edit-Mode Preview: Use the top-right Preview dropdown to inspect Japanese, Russian, or Chinese directly in Scene/Game View. Original text and fonts restore automatically on Ctrl+S, scene switch, or Play Mode.
  • 3D World Text & C# Prompts: Attach PWUI_LocalizedText to any 3D TextMeshPro object, or call PWUI_Locale.Get("PROMPT_PICKUP", itemName) from C#. Player language choice saves automatically to PlayerPrefs.

Wiring Menus & Silent Auto PlayerPrefs (Pinwheel Thread)

Pinwheel Thread flows strictly Left-to-Right: Blue: Triggers → Gold: Actions → Green: Targets. Every Gold Action node has ONE clean In port accepting unlimited incoming wires.

Step-by-Step: Wire Main Menu ↔ Settings (With Escape & Auto PlayerPrefs)

  1. Open Tools → Pinwheel Studios → Pinwheel Thread.
  2. Drag MainMenu_Screen from Hierarchy onto the grid as a Screen Buttons Card (Blue). Nested sub-panel buttons stay isolated automatically.
  3. Drag SettingsMenu_Screen onto the grid as a Menu Target (Green). Select it and check two boxes in the Inspector:
    • Start Disabled on Awake (purple START OFF pill — hides Settings automatically on boot)
    • Auto-Remember Controls (teal PREFS pill — silently saves & restores every Slider, Toggle, and Dropdown inside Settings with zero Save buttons)
  4. 3-Node Switch Menu: Add Switch Menu (Gold). Wire MainMenu_Screen [SETTINGS] → Switch Menu [In] and Switch Menu [Open] → SettingsMenu_Screen [In]. Because Auto-Close Source Screen is ON by default when Close is unwired, Main Menu closes automatically without dropping it twice.
  5. Back Button + Scoped Escape: Drag Settings' Btn_Back (Blue) and add Escape / Back Key (Blue). Wire BOTH into the exact same In port on Back (Auto-History) (Gold). Pressing Escape on the root Main Menu safely does nothing.
  6. Compile & Test: Click Auto-Tidy, confirm green ✓ Ready, and click COMPILE & CONNECT. Test saving/restoring in Play Mode, and use Clear Saved Prefs (Editor Test) in Thread's sidebar anytime to reset test data.
How Silent Automatic PlayerPrefs Memory Works Automatically discovers and binds every Slider (float), Toggle (bool), TMP_Dropdown (int), and legacy Dropdown (int) inside any checked panel—plus optional TMP_InputField text if you enable Also Remember Text Inputs. Writes in memory while dragging for zero stutter, flushes PlayerPrefs.Save() cleanly on panel leave/disable/pause/quit, restores values in Awake(), and invokes onValueChanged once in Start() so audio and graphics scripts apply saved settings on boot.

v1.6 Scene-Safe Reliability Protections

  • Scene-Switch Safe (Other Scene Badge): Switching to a Gameplay scene while Thread is open shows a calm blue Other Scene badge and preserves all graph references untouched instead of false red errors.
  • Rename-Proof & Move-Proof (GlobalObjectId): Tracks both GlobalObjectId and Hierarchy Path (with [#1]/[#2] duplicate-sibling protection) to self-heal moved or renamed objects automatically.

Sharing UI Across Different Unity Projects (.pwui & .pwthread)

  1. Export From Pinwheel Compose: Click More ▾ → Export Screen (.pwui) or Copy Blueprint on a single screen—or click Transfer ▾ in Compose's top bar to export/copy all screens in the scene.
  2. Import Into Another Unity Project: Your teammate clicks Transfer ▾ → Import .pwui File or Paste Blueprint. With Reskin Imported Screens to Active Theme checked (default), incoming menus automatically adopt their project's fonts, sprites, and colors with zero missing references.
  3. Share Node Flows (.pwthread): In Pinwheel Thread, click Share ▾ → Export Graph (.pwthread) or Copy Graph to Clipboard. Local GlobalObjectIds are stripped automatically so your teammate resolves clean paths and clicks COMPILE & CONNECT.

Connecting Gameplay & PurrNet Code (Custom Hook)

Never hand-edit PinwheelThread_UIFlow.cs because re-compiling overwrites it. Add a Custom Hook (Gold) node, set its C# Event Name (e.g., OnCreateLobbyClicked), click COMPILE & CONNECT, and subscribe cleanly from your own script:

LobbyNetworkBridge.cs — Pinwheel Thread Custom Hook Example 
using UnityEngine;

public class LobbyNetworkBridge : MonoBehaviour
{
    [SerializeField] private PinwheelThread_UIFlow uiFlow;

    private void OnEnable()
    {
        if (uiFlow != null)
            uiFlow.OnCreateLobbyClicked += HandleCreateLobby;
    }

    private void OnDisable()
    {
        if (uiFlow != null)
            uiFlow.OnCreateLobbyClicked -= HandleCreateLobby;
    }

    private void HandleCreateLobby()
    {
        // Trigger your PurrNet lobby creation or game logic here
        Debug.Log("[Pinwheel Studios] Creating PurrNet Lobby...");
    }
}

Pinwheel DreamSky — Procedural Night Sky Suite

Lightweight procedural night-sky shader and workflow tool. Repository: github.com/Bhavishya222/Unity-URP-DreamSky

Applies to: Pinwheel DreamSky Quick-Start & Reference

Overview, Quality Tiers, Installation & Usage

A procedural night-sky shader and workflow tool for Unity 6.3+ (URP 17), built for both stylized dark-fantasy worlds and realistic night scenes. Zero external dependencies, zero HDRP requirements, and strictly 3 shader variants (Low / Medium / High).

Key Features

  • Spherical Dome Starfield: Zero-loop, zero-texture-tap star layers with organic galactic clustering, dark voids, adjustable star size and variation, independent twinkling, and hero star cross-flares.
  • Domain-Warped Nebula: Pinch-free dome projection powered by a single packed RGBA noise atlas with 3-colour palettes, ridged filaments, and slow drift animation.
  • Animated Multi-Layer Clouds: Perspective dome clouds with independent layer speeds and moon-driven backlit rim glow.
  • Customizable Moon & Distant Celestials: Local tangent-plane projection (scaling never distorts the sky), procedural moon phases, earthshine, halo glow, custom texture support, and an optional ringed planet.
  • Procedural Shooting Stars: Time-sliced meteors driven purely on _Time.y with zero C# Update() loops.
  • Lower Hemisphere & World-Edge Blending: Switch below the horizon between Solid Gradient, Swirling Void Mist, or Fake Night Water (with synced moon shimmer), paired with an optional 1-draw-call Void & Water Plane shader and 1-click URP Horizon Fog sync.
  • Toggleable PS1/PS2 Retro Mode: World-locked spherical texel pixelation, perceptual 4×4 ordered Bayer dithering, and colour quantization.
  • Built-In Editor Texture Baker: Generates a seamless 4-channel RGBA noise atlas (Perlin / Worley / Ridged / Warp) and procedural lunar crater texture in one click.
  • Studio Setup Hub & Custom Inspector: 9-section collapsible Material Inspector, 4 style presets (Dreamy Fantasy, Dark Gothic Retro, Realistic Night, Twilight Mist), and an optional zero-GC PWSky_Controller for Directional Light moon syncing and runtime preset crossfading.

Installation

  • Option 1 — Unity Package (Recommended): Download PinwheelDreamSky-v1.0.0.unitypackage from the GitHub Releases page, then go to Assets → Import Package → Custom Package... in Unity 6.3+ (URP).
  • Option 2 — Manual: Copy Assets/PinwheelStudios/DreamSky/ into your project's Assets/PinwheelStudios/ folder.

Quick Start

  1. Open Tools → Pinwheel Studios → Pinwheel DreamSky.
  2. Pick a Style Preset and Quality Tier, then click Create & Apply Skybox to Scene (default textures bake automatically on first use into Assets/PinwheelStudios/Generated/DreamSky/).
  3. (Optional) Click Sync Scene Fog to Skybox Horizon Colour to hide distant terrain borders.
  4. (Optional) Click Spawn Synced Void / Water Plane to wrap mist or night water around cliff bases and floating islands.
  5. (Optional) Click Create / Select Sky Controller to sync the Skybox Moon to your scene's Directional Light.

Unity MeshLOD Studio — Documentation

Prefab-first LOD management and conversion tool. Repository: github.com/Bhavishya222/Unity-MeshLOD-Studio

Applies to: Unity MeshLOD Studio Quick-Start Guide

Overview, Installation & Usage

Unity's built-in Generate Mesh LODs feature lacks support for Static Batching, GPU Instancing, per-LOD material overrides, and custom transition thresholds. Unity MeshLOD Studio losslessly extracts generated Mesh LOD index buffers into compact standalone meshes and builds configurable LODGroup setups directly on your Prefab assets.

Core Features

  • Prefab-First Workflow: Modifies the source .prefab asset safely so scene instances inherit updates without breaking instance-specific overrides.
  • Lossless LOD Extraction: Uses Mesh.AcquireReadOnlyMeshData to extract and vertex-compact individual LOD levels without modifying original FBX models.
  • Zero-Conflict LODGroups: Preserves your original MeshFilter/MeshRenderer for LOD0 to maintain FileIDs, scripts, and scene material overrides while building child nodes for LOD1+.
  • Batch Optimizer & Scene Auto Setup: Batch-process hundreds of prefabs or scan a full scene to group and update unique source prefabs.
  • Preset Manager: Save, reuse, import, and export JSON presets (High Quality, Balanced, Performance) mapping screen-relative heights or real-world distances.

Installation

  1. Download or clone Unity-MeshLOD-Studio from GitHub.
  2. Place the Assets/Editor/MeshLODStudio folder into your Unity project.
  3. Allow Unity to compile the included .asmdef file.
  4. Open via Tools → MeshLOD Studio → Open Studio.

Usage

  1. Ensure your 3D models have Generate mesh LODs enabled in their Model Importer (or use the 1-click enable button inside the tool).
  2. Open Tools → MeshLOD Studio → Open Studio.
  3. Select a .prefab asset in your Project window and review the structural analysis in the Prefab Studio tab.
  4. Switch to the Mesh LOD Converter tab, select an optimization Preset, and click Convert Selected Objects & Save Prefab.

Unity URP World Rescaler — Documentation

One-click scene, Terrain, collider, and URP light rescaler. Repository: github.com/Bhavishya222/Unity-URP-World-Rescaler

Applies to: Unity URP World Rescaler Quick-Start Guide

Overview, Installation & Usage

Scaling a root GameObject in Unity breaks multi-tile terrain physics and ignores light ranges. Unity URP World Rescaler calculates exact proportions and clones terrain assets so oversized maps shrink cleanly in one click.

Features

  • Safe Hierarchy Scaling: Repositions root objects without skewing nested terrain scale constraints.
  • Terrain Cloning: Duplicates TerrainData and TerrainLayers before modifying them to preserve painted splatmaps and prevent stretched textures.
  • Physics Sync: Automatically updates invisible TerrainCollider dimensions to match the visual mesh.
  • URP Lighting Scaling: Scales Point/Spot light ranges and Camera clip planes to match the new world size, with an optional toggle to adjust light intensity.

Installation

  1. Download WorldRescalerWindow.cs from GitHub.
  2. Drop it anywhere inside an Assets/Editor folder in your Unity project.

Usage

  1. Open Tools → World Rescaler from the top menu bar.
  2. Set your Scale Factor (for example, if your world is 5× too big, set Scale Factor to 0.2).
  3. Check the options relevant to your scene (Terrain scaling, URP light ranges, etc.).
  4. Click Scan Active Scene to check for structural blockers, then click Apply Rescale.
Backup & Re-Bake Note Always save a project backup before modifying scene scales. Baked lightmaps, NavMesh data, and fog distances will need to be re-baked manually after rescaling.
