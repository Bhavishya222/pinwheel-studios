Package 2

              
Pinwheel Thread

              
Tools → Pinwheel Studios → Pinwheel Thread

              

                A visual Left-to-Right node editor for wiring Buttons, Escape keys, Auto-History navigation, Start Disabled rules, and Refresh Panel resets into a single generated C# router script.
              

              
    
                
  • Tracks objects via GlobalObjectId and Hierarchy Path so renaming or moving objects will not break wires
    • 
                
  • Pre-compile Health Badge, Prefab Mode guard, and additive multi-scene support
    • 
                
  • Multi-Input action nodes let buttons and keyboard shortcuts share one action
    • 
                
  • Custom Hook C# events for PurrNet and gameplay scripts without editing generated code
    •

Unity MeshLOD Studio

              

                A Prefab-first LOD management and conversion tool for Unity 6.3+. Losslessly extracts generated Mesh LOD index buffers into compact standalone meshes and builds configurable LODGroup setups directly on your source .prefab assets.
              

              
    
                
  • Lossless Extraction: Uses Mesh.AcquireReadOnlyMeshData to vertex-compact LOD levels without modifying original FBX models.
    • 
                
  • Zero-Conflict LODGroups: Preserves your original MeshFilter/MeshRenderer on LOD0 to maintain FileIDs, scripts, and scene overrides.
    • 
                
  • Batch & Scene Auto Setup: Batch-process hundreds of prefabs or scan a scene to update unique source prefabs automatically.
    • 
                
  • JSON Preset Manager: Save, reuse, import, and export screen-relative height or distance profiles.
    •

Unity URP World Rescaler

              

                A Unity Editor extension to rescale entire scenes, nested Terrains, and URP lights in one click without breaking terrain physics, painted splatmaps, or texture tiling.
              

              
    
                
  • Safe Hierarchy Scaling: Repositions root objects without skewing nested multi-tile terrain scale constraints.
    • 
                
  • Terrain Cloning: Duplicates TerrainData and TerrainLayers before scaling to preserve painted splatmaps.
    • 
                
  • Physics Sync: Automatically updates TerrainCollider dimensions to match the rescaled visual mesh.
    • 
                
  • URP Lighting & Camera Sync: Scales Point/Spot light ranges, camera clip planes, and optional light intensity.
    •
